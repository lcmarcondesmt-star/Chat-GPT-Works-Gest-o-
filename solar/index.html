Configurar a implantação

Por padrão, cada mesa tem 2 fileiras de módulos transversais. O comprimento da mesa usa o lado curto do módulo; sua profundidade usa duas vezes o lado longo, com folgas.

Solo: a profundidade é projetada no terreno, usando cos(ângulo), sem cálculo de sombras. Telhado: informe comprimento e profundidade medidos sobre o próprio plano inclinado.

Atribuição manual
Criar nova string

Clique nas placas individualmente; use Shift para intervalo na mesma mesa, ou Ctrl/Cmd para multisseleção. Depois atribua à string.

Distribuição automática • projeto novo

Em mesas curtas, o modo automático prioriza blocos de duas fileiras (por exemplo, 2×5). Em mesas longas, distribui grupos em fileiras retas.

A redistribuição é somente geométrica: forma strings inteiras de N módulos por mesa; usa as sobras no final se possível; módulos insuficientes ficam sem string, não são forçados para uma string curta. Não verifica Voc, Vmp, Isc, MPPT ou potência admissível.
